# Shelf Life Table

Default shelf lives for all perishable products in Fresh. Values are in game months at Normal difficulty.

> **Note:** This documentation was generated with AI assistance and may contain inaccuracies. If you spot an error, please [open an issue](https://github.com/rittermod/FS25_Fresh/issues).

---

## How to Read This Table

- **Shelf Life** - Time before expiration at Normal difficulty, in Sheltered storage (1.0x multiplier)
- **Max Benefit** - The best storage class that improves this product's shelf life. Better storage than this has no additional effect.
- All values can be customized per product in the Fresh Menu settings

### Difficulty Preset Multipliers

| Preset | Multiplier | Effect |
|--------|-----------|--------|
| Very Easy | ×4 | Quadrupled shelf life |
| Easy | ×2 | Doubled shelf life |
| Normal | ×1 | Default values below |
| Hard | ×0.5 | Halved shelf life |

## Non-Expiring Products

The following categories of products do not expire:

- **Farm supplies** - Fertilizer, herbicide, lime, liquid fertilizer, mineral feed, silage additive
- **Natural resources** - Cotton, wool, manure, liquid manure, digestate
- **Wood and construction** - Boards, planks, wood beams, cement, bricks, prefab walls
- **Manufactured goods** - Furniture, clothes, fabric, pianos, barrels, rope, tarp
- **Fuel and energy** - Diesel, DEF, electric charge, methane
- **Animals** - All animal fill types
- **Bale materials** - Net wrap, twine, wrapping film

*Non-expiring products are hidden from the Fresh Menu by default. Products not listed in the mod's configuration default to non-expiring.*

---

## DLC and Mod Products

Fresh automatically detects fill types added by DLCs, maps, and other mods. New fill types default to non-expiring unless you configure them in the Settings tab of the Fresh Menu. The settings distinguish between basegame products and DLC/mod products in separate tabs for easy management.
